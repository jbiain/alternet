# Contribute / where this is going

This is an early, hand-built network. The best way to help right now:
- Run a node and keep it pinned to a few sites you care about.
- Publish something: a page, a small board, a mirror of public text you like.
- Report what breaks; the rough edges are the actual roadmap.

Open questions we're working through: readable names without a central registry (petnames and
signed directories), encrypted private content, low-bandwidth radio links (LoRa), and whether to
build a simple broadcast "station" format. See the project's `docs/` if you have the source.
