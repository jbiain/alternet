# ALTERNET BBS

A terminal-first, decentralised network. No accounts, no company, no server you rent.
Sites are signed and content-addressed; a trusted friend's copy keeps your site up when your
computer is off.

## Main menu

1. [about.md](about.md)       - what this is and why it exists
2. [install.md](install.md)   - get the `alternet` command running
3. [commands.md](commands.md) - the command reference
4. [demo.md](demo.md)         - boards you can visit right now
5. [contribute.md](contribute.md) - how to help, and where this is going
6. [agents.md](agents.md)     - reading this as an AI assistant? start here
7. [why.md](why.md)           - why this is different, and `alternet tour` to see it work

Read any page with:  `alternet read <this-site-id> <page>`
Or in a browser, through a gateway:  `alternet gateway`
