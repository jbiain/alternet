# Alternet Manifesto (summary)

- Be a participant, not a renter. Every home computer is capable of taking part.
- The network has no owner. No single company or server controls it.
- Identity is a key, not an account. Names are local labels, never a central registry.
- Content is verified, not trusted by default. Every page is signed and hash-checked before
  it is stored or shown.
- Any link will do. Wi-Fi, a hotspot, a cable, a relay, or a USB stick move the same signed
  bundle unchanged.
- Small and legible beats big and vague. The network should stay understandable by the people
  who run it.
