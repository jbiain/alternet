# About Alternet

The internet today means renting space on someone else's platform: hosting, DNS, app stores,
cloud providers. Alternet lets ordinary computers publish and replicate signed text sites with
no central server, no accounts, and no dependency on anyone staying online.

A site is a signed, content-addressed set of pages. Anyone holding a verified copy can serve it;
there is no "real" host that content depends on, as long as one honest copy exists somewhere.

Two proofs drive the design:
- Two or three machines with no internet can publish, discover and read a signed site.
- A site survives its original host going offline, served from a trusted peer's copy.

Read more: `manifesto.md` (`about:manifesto` from here), and the project's `docs/` folder if
you have the source.
